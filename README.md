# naming\n\nA [Claude Code](https://docs.anthropic.com/en/docs/claude-code) skill for naming products, SaaS tools, brands, and projects.\n\nThis skill uses metaphor-driven naming to create memorable and meaningful names — avoiding common AI-generated noise.\n\n## What this does\n\nWhen you run this skill, Claude guides you through a clear 7-step naming process:\n\n1. **Naming brief** — Define what the product does, who it's for, and the desired feeling.\n2. **Metaphor exploration** — Explore related conceptual ideas before brainstorming names.\n3. **Candidate generation** — Create names based on metaphors rather than synonyms.\n4. **Filtering** — Remove low-quality or generic AI-generated names.\n5. **Evaluation** — Score and compare finalists using a weighted rubric.\n6. **Availability checking** — Check domains, social media handles, and package names.\n7. **Decision** — Present top candidates with their origin stories and trade-offs.\n\n## Install\n\n### As a project skill (for this project only)\n\nClone or copy the repository into your project's `.claude/skills/naming/` folder:\n\nbash\n# From your project root\mkdir -p .claude/skills\ngit clone https://github.com/glacierphonk/naming.git .claude/skills/naming\n\n\n### As a personal skill (for all projects)\n\nbash\nmkdir -p ~/.claude/skills\ngit clone https://github.com/glacierphonk/naming.git ~/.claude/skills/naming\n\n\n## Usage\n\nIn Claude Code, start by typing:\n\ntext\n/naming\n\n\nThen briefly describe what you need a name for. and required sections.\n\n## Philosophy\n\n**Names are compressed stories, not labels.** The best names create strong images that reveal what the product does, how it feels, and where it comes from.\n\nThis skill is opinionated:\n\n- **Metaphor over thesaurus.** Avoid searching for synonyms of your product’s category. Instead, find what else in the world works like your product.\n- **Real words over invented words.** Real-word brand names have about 68.8% recall compared to 38.1% for invented names. The brain prefers familiar paths.\n- **Story over sound.** A name with an interesting origin story and average sound beats a perfect-sounding name without a story.\n- **Kill AI slop.** Avoid suffixes like -ly, -ify, -able, meaningless portmanteaus, and thesaurus-based names. This skill filters them out intentionally.\n\n## How the skill uses context\n\n- **Always loaded:** Skill name and description (about 2% of context budget)\n- **Loaded on invoke:** `SKILL.md` (around 180 lines) with the process overview\n- **Loaded on demand:** Reference files load only when Claude reaches that step.
