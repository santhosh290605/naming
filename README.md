# naming\n\nA [Claude Code](https://docs.anthropic.com/en/docs/claude-code) skill for naming products, SaaS tools, brands, and projects.\n\nThis skill uses metaphor-driven naming to create memorable and meaningful names — avoiding common AI-generated low-quality names.\n\n## What this does\n\nWhen you invoke this skill, Claude guides you through a structured naming process:\n\n1. **Naming brief** — Define what the product does, who it is for, and the desired feeling.\n2. **Metaphor exploration** — Explore conceptual territories related to your product before brainstorming names.\n3. **Candidate generation** — Create name options grounded in metaphor, not just thesaurus searches.\n4. **Filtering** — Eliminate AI-generated nonsense and weak patterns.\n5. **Evaluation** — Score and compare finalists using a weighted rubric.\n6. **Availability checking** — Verify domain, social handles, and package name availability.\n7. **Decision** — Present the top candidates along with their origin stories and trade-offs.\n\n## Install\n\n### As a project skill (available only in this project)\n\nClone or copy the repository contents into your project's `.claude/skills/naming/` directory:\n\nbash\n# From your project root\nmkdir -p .claude/skills\ngit clone https://github.com/glacierphonk/naming.git .claude/skills/naming\n\n\n### As a personal skill (available in all your projects)\n\nbash\nmkdir -p ~/.claude/skills\ngit clone https://github.com/glacierphonk/naming.git ~/.claude/skills/naming\n\n\n## Usage\n\nIn Claude Code, type:\n\ntext\n/naming\n\n\nThen describe what you need a name for. Claude will guide you through the full naming process.\n\nYou can also mention this skill naturally in conversation — just describe your naming challenge, and Claude will use the relevant references.\n\n### Quick start\n\nYou don’t need to read any reference files before using the skill. labels.** The best names evoke a concrete image that unfolds into understanding what the product does, how it feels, and where it comes from.\n\nThis skill follows these principles:\n\n- **Metaphor over thesaurus.** Don’t just find synonyms; explore what else in the world functions like your product.\n- **Real words over invented words.** Real-word brand names have about 68.8% recall compared to ~38.1% for invented names. The brain follows the path of least resistance.\n- **Story over sound.** A name with a strong origin story but average sound usually outperforms a name with perfect phonetics but no story.\n- **Kill AI slop.** Avoid suffixes like -ly, -ify, -able, meaningless portmanteaus, and thesaurus-derived names. This skill filters out polished but generic names.\n\n## How the skill uses context\n\n- **Always loaded:** Skill name and description (about 2% of context budget)\n- **Loaded on invoke:** `SKILL.md` (about 180 lines, the process overview)\n- **Loaded on demand:** Reference files load only when Claude reaches the relevant step. Simple naming tasks might load only 2–3 files; thorough sessions may load 5–6.\n- **Never auto-loaded:** Language files and `case-studies.md` load only when explicitly relevant.\n\nContributors: keep reference files focused.
